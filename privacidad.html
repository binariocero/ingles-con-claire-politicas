Política de privacidad

Última actualización: 21 de noviembre de 2026

1. Finalidad

Esta política describe el uso de la herramienta interna del canal «Inglés con Claire y Mattew» (en adelante, «la Herramienta») para publicar vídeos y consultar estadísticas del propio canal mediante las API de YouTube.

2. Datos tratados

La Herramienta se autentica con la cuenta del propio titular mediante OAuth 2.0 de Google y solo accede a los datos del canal autorizado: subida de vídeos, metadatos del canal y estadísticas agregadas de YouTube Analytics. No recopila, almacena ni procesa datos personales de terceros ni de los espectadores.

3. Almacenamiento y seguridad

Las credenciales OAuth se guardan únicamente en el equipo local del titular, con permisos restringidos, y no se comparten, publican ni transmiten a terceros. No se usan servicios de terceros para el tratamiento de estos datos.

4. Servicios de Google

El uso de las API de YouTube se rige por los Términos del Servicio de las API de YouTube y la Política de Privacidad de Google. La Herramienta no vende ni cede datos de las API de YouTube.

5. Derechos y contacto

Para cualquier consulta sobre esta política o sobre la Herramienta, escribe a ggq302@gmail.com.

6. Cambios

Cualquier cambio en esta política se publicará en esta misma página.
